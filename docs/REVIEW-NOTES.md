# Notes for Review (App Store Connect)

Moved on 28 Oct 2026 to [APP_REVIEW_NOTES.md](APP_REVIEW_NOTES.md): the Notes text as written to App Store Connect (read back, matches), every server feature with its switch, and what to do before submitting. The 26 Oct copy in store/apple/review-notes.md now points there too.

Why the notes list server features: App Review Guideline 2.5.19 (added 16 Oct 2026) does not allow hidden, dormant or undocumented features, 2.5.2 asks that an app downloads no code that changes its features, and 2.3.1(a) asks for new features to be described in Notes for Review.
