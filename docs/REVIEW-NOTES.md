# Notes for Review (App Store Connect)

Moved on 26 Oct 2026 (g25) to [store/apple/review-notes.md](../store/apple/review-notes.md): the Notes text as written to App Store Connect (read back, matches), what changed and what to do before submitting.

Why the notes list server features: App Review Guideline 2.5.19 (added 16 Oct 2026) does not allow hidden, dormant or undocumented features, and 2.3.1(a) asks for new features to be described in Notes for Review.
